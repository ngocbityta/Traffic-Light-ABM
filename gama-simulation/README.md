# GAMA simulation

Thư mục này chỉ chứa mô hình GAMA cho nút giao Lê Văn Lương – Hoàng Đạo Thúy.
Trong GAMA Studio, import thư mục `gama-simulation/`, mở
`simulation/models/LeVanLuong.gaml` và chạy experiment `main`.

- `simulation/models/`: model GAML.
- `simulation/includes/`: mạng đường và khu vực dưới dạng GeoJSON.
- `scripts/`, `tests/`, `ui/`: điểm đặt cho công cụ, kiểm thử và tài nguyên giao diện của mô phỏng.
